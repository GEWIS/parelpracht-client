# ParelPracht Client

This is the front-end of ParelPracht. [The back-end can be found here](../parelpracht-server).

## Installation
1. Clone the repository.
2. Run `yarn install`.
3. Run `yarn run start`. This runs the client in development mode. You can view it at [http://localhost:3000](http://localhost:3000).

You can also build the application with `yarn run build`. This puts a production build in the `./build` directory.
